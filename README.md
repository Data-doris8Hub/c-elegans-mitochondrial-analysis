# 🧬 Nucleotide Frequency Analysis in *C. elegans*

## 📌 Project Overview

This project analyzes the nucleotide frequencies in the mitochondrial genome of *Caenorhabditis elegans*.

The objective is to evaluate whether the nucleotide distribution follows a uniform model (equal probability for A, T, C, and G).

---

## 🎯 Objectives

* Compute nucleotide frequencies
* Test the hypothesis of uniform distribution
* Perform simulations to validate results

---

## 🧪 Methods

* Sequence analysis using R
* Bioconductor package (Biostrings)
* Statistical simulation

---

## 🛠️ Tools

* R
* Biostrings
* ggplot2

---

## 📊 Results

Preliminary results suggest that nucleotide frequencies are not equally distributed, indicating biological biases.

(Results will be updated with visualizations)
