Analyse du biais nucléotidique dans le génome mitochondrial de C. elegans

Introduction

La composition nucléotidique est une propriété fondamentale des génomes. Elle fournit des informations sur l’organisation moléculaire de l’ADN, les contraintes évolutives et les mécanismes de mutation et de réplication.

Chez de nombreux organismes, les génomes mitochondriaux présentent une composition nucléotidique distincte de celle du génome nucléaire, souvent marquée par un fort biais AT.

Chez Caenorhabditis elegans, le génome mitochondrial est connu pour sa richesse en adénine (A) et thymine (T). Cette particularité soulève une question importante : la distribution des nucléotides dans l’ADN mitochondrial suit-elle un modèle uniforme (chaque base à 25 %) ?

L’objectif de cette étude est double :

  1. Tester si la composition nucléotidique du chromosome mitochondrial (chrM) suit un modèle uniforme à l’aide d’une simulation de Monte Carlo.

  2. Comparer cette composition à celle du génome nucléaire (chrI).

Cette analyse est réalisée avec R et l’écosystème Bioconductor.

Le génome mitochondrial présente un fort biais AT (76,2 %), avec une asymétrie marquée : 44,8 % de T contre 31,4 % de A. Par contre, le génome nucléaire est plus équilibré (environ 64 % AT).

On observe également que A ≠ T et G ≠ C dans le génome mitochondrial, ce qui constitue une violation de la règle de Chargaff (contrairement au génome nucléaire où A ≈ T et G ≈ C).

4. Test statistique par simulation de Monte Carlo

#Formule de Khi2
chi2_stat <- function(counts){
  expected <- sum(counts)/4
  sum((counts - expected)^2 / expected)
}

obs_chi2 <- chi2_stat(counts=freq_mito)
obs_chi2
[1] 7835.134

Le Chi² observé est de 7835.13.

#Paramètre de simulation
set.seed(123)
n_sim <- 10000
sim_chi2 <- numeric(n_sim)
len <- length(mito_M)
#Simulation de Monte Carlo
for(i in 1:n_sim){
  random_seq <- sample(c("A","C","G","T"),size=len,replace=T)
  counts <- table(random_seq)
  sim_chi2[i] <- chi2_stat(counts)
}
# p-value de la simulation de Monte Carlo
p_value <- mean(sim_chi2 >= obs_chi2)
p_value
[1] 0

La p-value étant égale à 0, alors sur les 10 000 simulations réalisées sous l’hypothèse d’un modèle uniforme, aucune n’a produit un Chi² supérieur ou égal à celui observé (7835.13). Ainsi, nous rejetons très fortement l’hypothèse selon laquelle les nucléotides sont distribués uniformément dans le génome mitochondrial.

7. Conclusion

Cette analyse a mis en évidence un fort biais AT dans le génome mitochondrial de C. elegans (76,2 %), avec une composition nettement différente de celle observée dans le génome nucléaire.

La simulation de Monte Carlo (10 000 itérations) a permis de rejeter très significativement l’hypothèse d’une distribution uniforme des nucléotides (Chi² = 7835,13 ; p-value = 0) confirmant que cet écart n’est pas dû au hasard.

De plus, la comparaison avec le chromosome I nucléaire montre que le mtDNA présente une asymétrie marquée (A ≠ T et G ≠ C), ce qui constitue une violation de la règle de Chargaff classique.

Ces résultats sont cohérents avec les connaissances biologiques selon laquelle les mitochondries subissent un biais mutationnel important (notamment C→T), renforcé par leur environnement oxydatif et leur mode de réplication asymétrique.
